# Koin OpenHarmony 接入指南

当前宿主沿用已验收版本 `4.1.1-ohos-2.2.21-8-rc.1`，发布状态、冻结归档及该版本验收以精确 [Release](https://github.com/gycrosskit/koin-ohos/releases/tag/4.1.1-ohos-2.2.21-8-rc.1) 为准。Core 三端消费映射、历史验证和未验收范围见[功能与平台差异](功能与平台差异.md)。 本轮只合并源码清理，不发布新制品；该旧 RC 归档不包含本次 CMP 物理删除。

基础仓库和依赖配置见 [README](../README.md#安装)。`commonMain` 沿用 `org.koin` API；Android 使用 JVM 变体，iOS/OHOS 使用 Native 变体。

## 依赖身份与历史兼容验证

本 fork 只发布 Core，保留上游 `io.insert-koin` / `co.touchlab` KLIB 身份，Maven Publication 使用 fork 组名；同一个二进制只能解析到一份 Core 和每个 Stately 模块。退出独立 CMP 维护不改变已发布 KLIB 身份或公共 API。

当前不再维护 `verification-compose-consumer` 或官方 Compose 接线。旧版混用配置及已发布验证事实保留在 [4.1.1-ohos-2.2.21-7 接入指南](https://github.com/gycrosskit/koin-ohos/blob/4.1.1-ohos-2.2.21-7/docs/接入指南.md)；复验旧版本时检出该 tag，使用其原消费者。当前源码已删除上游 Compose 模块、示例及专属构建和教程；Core、原生模块、许可证与版本历史保留。该删除不修改历史版本的不可变 tag、归档或校验值。

## 状态与生命周期

`koinApplication { ... }` 创建独立容器；由持有它的宿主管理生命周期，并在所有调用结束后执行 `close()`。需要上游全局上下文时可使用 `startKoin` / `stopKoin`；不要随页面状态更新重复启动容器。
