## Core 与适配分支

本 fork 仅构建发布 `koin-core`，包保持 `org.koin`，基于上游 Koin4.1.1；不发布 koin-compose、koin-compose-viewmodel、koin-android、Ktor 或 Kuikly ViewModel 模块。[ohos-probe](../ohos-probe/settings.gradle.kts) 指向 [Core](../projects/core/koin-core/build.ohos.gradle.kts)，与上游 `projects` 的全模块构建不同。

OpenHarmony 适配维护在 **codex/ohos-4.1.1**，默认 **main 是上游基线**；main 更新不代表本 fork 已适配/发布。Native 传递使用 Stately OHOS；保留上游 KLIB 身份，Maven 组名为本 fork，不能同时装入两份同名 KLIB。

| 五种入口 | 实际映射 | 生命周期接线 |
| --- | --- | --- |
| CMP Android | Core common + JVM actual，Android 消费 JVM 变体 | 宿主管理容器；官方 Compose 扩展需独立依赖与替换 |
| CMP iOS | Core common + Native/Stately actual | 同上；官方 Compose 混用默认缓存链接有历史验证 |
| Kuikly Android | 同 JVM Core | UI/页面 scope 与 ViewModel 生命周期由宿主接线 |
| Kuikly iOS | 同 Native Core | 同上；无 Kuikly 专用模块 |
| Kuikly OHOS | 同 Native Core + OHOS Stately | 使用 OHOS 工具链；官方 Compose 扩展不会因此获得 OHOS 变体 |

## 公开 API / 功能分组与三端差异

| 功能组 / 生产入口 | 共用行为 | Android / iOS / OHOS 差异 |
| --- | --- | --- |
| [Koin](../projects/core/koin-core/src/commonMain/kotlin/org/koin/core/Koin.kt) / [DSL](../projects/core/koin-core/src/commonMain/kotlin/org/koin/dsl/ModuleDSL.kt) | single、factory、scoped、get/getOrNull/inject、qualifier、parameters、load/unload modules | 定义/解析逻辑在 commonMain；平台锁及上下文实现不同 |
| [Scope](../projects/core/koin-core/src/commonMain/kotlin/org/koin/core/scope/Scope.kt) / [ScopedInstanceFactory](../projects/core/koin-core/src/commonMain/kotlin/org/koin/core/instance/ScopedInstanceFactory.kt) | scope 创建/查找/链接、scoped 实例隔离、ScopeCallback、onClose、close | 三端共用相同 Core；页面何时释放不是 DI 自动判断 |
| [JVM GlobalContext](../projects/core/koin-core/src/jvmMain/kotlin/org/koin/core/context/GlobalContext.kt) / [Native context](../projects/core/koin-core/src/nativeMain/kotlin/org/koin/core/context/GlobalContext.kt) | startKoin/stopKoin；独立 `koinApplication` 不共享全局容器 | Android 使用 JVM object；iOS/OHOS 使用 Native MutableGlobalContext + Stately Lock |

`org.koin` 公共声明是能力边界；仓库保存的上游 Compose/Android 文档和源码不等于本 fork 发布了这些扩展。

## 差异分类与关闭合同

- **组件范围/不提供的入口**：本 fork 只提供 Core，不发布 CMP/Kuikly UI 或 ViewModel 模块；页面与 ViewModel 生命周期由宿主或另行引入的官方扩展接线。这些范围边界不代表本 fork 待新增的 UI 实现。
- **OS/SDK 限制**：OHOS 使用 Kotlin2.2.21-1.0.0 与 Native SDK；Native 构建需对应平台工具链。未独立确定最低 iOS/OHOS 设备版本。
- **宿主职责**：共享容器的 owner、启动/停止时机、scope 与页面生命周期、品牌 module/凭据注入；不在 Compose 重组中反复 startKoin。所有调用结束后再关闭。
- **本轮修复**：Scope.close 新增 closing guard，重复或 callback 重入不再次销毁；保持 callback 中 `scope.get()` 可取原 scoped 实例的顺序。ScopeCallback 异常仍传播并阻断本次关闭，finally 清 closing 后可重试；已运行 callback 在重试时可能再次执行。JVM/Native stopKoin 成功关闭后同时清旧 KoinApplication。删除单调用 globalContextByMemoryModel wrapper，无新上下文架构。
- **未验收**：高并发创建/解析/销毁压力、真实 OHOS/iOS 业务页面生命周期与多品牌 module；源码共用或链接成功不等于这些验收通过。
