# GY CrossKit Koin OpenHarmony

这是 [Koin 上游](https://github.com/InsertKoinIO/koin) 的 OpenHarmony 适配 fork。已发布的 KMP 产物供 Android/JVM、iOS 与 OHOS 消费，具体模块、工具链与验证范围见适配分支。

默认 `main` 保留上游源码基线，**不代表 OpenHarmony 发布实现**。接入本 fork 请使用下列入口，勿直接套用上游依赖坐标：

- [OpenHarmony 接入 README](https://github.com/gycrosskit/koin-ohos/blob/codex/ohos-4.1.1/README.md)：模块、远程坐标、工具链及使用示例。
- [适配源码](https://github.com/gycrosskit/koin-ohos/tree/codex/ohos-4.1.1)：实际维护与发布分支 `codex/ohos-4.1.1`。
- [Releases](https://github.com/gycrosskit/koin-ohos/releases)：固定版本与发布归档。
- [Issues](https://github.com/gycrosskit/koin-ohos/issues)：适配问题请附版本、平台和脱敏复现。
- [上游文档](https://github.com/InsertKoinIO/koin#readme)：通用 API 与上游项目说明。

本 fork 保留上游来源与 [Apache-2.0 许可证](LICENSE)。安装说明仅在适配分支维护，避免默认分支与发布分支出现两套版本信息。
